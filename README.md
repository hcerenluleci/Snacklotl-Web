# SnackLotl 🎮

Klasik yılan oyununun Axolotl temalı eğlenceli ve tatlı bir versiyonu!

## Nasıl Oynatılır / Çalıştırılır?

1. Bu projeyi bilgisayarınıza indirin veya klonlayın.
2. `index.html` dosyasını herhangi bir modern web tarayıcısında (Chrome, Edge, Firefox vb.) açın.
3. Yön tuşlarını kullanarak Axolotl'u hareket ettirin ve balıkları toplayarak büyüyün!

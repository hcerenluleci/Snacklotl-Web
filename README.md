# SnackLotl

An underwater axolotl food journey browser game built with HTML5, CSS3, and Vanilla JavaScript. Guide your axolotl to collect delicious underwater snacks while avoiding harmful toxins.

---

## Features

- **Interactive Gameplay**: Smooth keyboard controls (`A`/`D` or arrow keys) and touch support for mobile devices.
- **Animated Character**: Dynamic sprite animations when your axolotl successfully grabs a treat.
- **Progressive Difficulty**: The game speeds up as your score increases, keeping the challenge fresh.
- **Persistent Stats**: Tracks and saves your high score using `localStorage`.
- **Audio & Mute Control**: Atmospheric background music with an easy-to-use toggle.
- **Analytics Ready**: Integrated with Vercel Web Analytics.

---

## How to Play

1. **Start the Game**: Press **SPACE** or tap the screen on the start menu.
2. **Move**: Use **A** / **D** keys, **Left** / **Right** arrow keys, or drag your finger across the screen.
3. **Collect Snacks**: Grab shrimp (`+1 point`) and fish (`+1 point`).
4. **Avoid Toxins**: Steer clear of the green toxins (`-1 life`). You have 3 lives in total.
5. **Game Over**: When your lives run out, press **R** to restart or **Q** to quit.

---

## Built With

- **HTML5 Canvas** for rendering the game graphics.
- **CSS3** for responsive layout and styling.
- **Vanilla JavaScript (ES6+)** for game logic, collision detection, and event handling.
